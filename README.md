# 🚗 Car Price Prediction & Model Comparison

## 📌 Project Overview

This project focuses on predicting the price of used cars using Machine Learning regression algorithms.

The dataset contains different car-related features such as brand, model, manufacturing year, transmission, mileage, fuel type, tax, MPG, and engine size.

Multiple regression models are trained and evaluated to determine which model performs best for car price prediction.

---

## 🎯 Project Objective

The main objectives of this project are:

- Load and understand the car dataset
- Perform data inspection and cleaning
- Analyze categorical and numerical features
- Perform Exploratory Data Analysis (EDA)
- Encode categorical variables
- Split data into training and testing datasets
- Apply feature scaling where required
- Train multiple Machine Learning regression models
- Evaluate model performance
- Compare different regression algorithms
- Select the best-performing model
- Save the trained model using Joblib

---

## 📂 Dataset

The dataset used in this project is `car.csv`.

### Dataset Features

| Feature | Description |
|---|---|
| `brand` | Brand of the car |
| `model` | Model of the car |
| `year` | Manufacturing year |
| `transmission` | Type of transmission |
| `mileage` | Distance travelled by the car |
| `fuelType` | Type of fuel used |
| `tax` | Vehicle tax |
| `mpg` | Miles per gallon |
| `engineSize` | Engine size |
| `price` | Price of the car |
